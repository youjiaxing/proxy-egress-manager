    列表布局

    一个分组就是一个固定的代理入口。业务使用这个入口，系统负责选择和检查背后的代理节点；换节点后，入口地址不变。

    分组怎么用？查看名词和操作说明

    首次使用：先添加并启用订阅。如果分组显示“启用分组”，先点它，再等待检查结果。点击“配置分组”，选择自动优选节点池，或查看质量后手动勾选多个节点；确认保存后，正常使用池内一个，故障后在池内切换。只有显示“可用”后，业务才能通过该组连接。

    卡片里的代理地址供服务器上已接入共享网络的业务容器填写，不能直接填到个人电脑上。不同分组会检查出口地址是否重复；检查只覆盖设置中的检测目标，不能保证所有网站看到的地址都不同。

    节点、订阅和出口 IP
    订阅提供可选择的代理服务器，这些服务器称为“节点”；出口 IP 是检测服务器实际看到的公网地址。TCP 和 UDP 是两种通信方式，系统都会验证。
    检查连接
    立即安排一次全组检查；手动暂停的组仍保持暂停。没有合格节点时，系统可能继续寻找替代节点，这不只是测速。
    配置分组
    统一配置可用节点池：自动优选会推荐最多 3 个供确认，手动选择可查看质量、延迟并多选。分组可用且当前节点仍在新池内时保持连接；暂不可用时，修改范围会启动查找。
    立即切换当前节点（更多操作）
    让系统选择或手动指定当前使用的一个节点，不修改节点池。只有通过美国归属、TCP / UDP 连接和与其他组出口不重复的检查后才可使用；切换会断开已有连接。
    启用 / 暂停分组
    启用后等待验证，不保证立即可用。暂停会停止该入口并断开已有连接，直到你再次启用。
    固定当前节点
    不允许自动更换当前节点；节点故障或验证不通过时，该组会停止转发。可以设置多久后自动解除固定，或手动解除。固定节点不等于固定公网 IP。
    允许自动换节点
    解除固定。正常时保持当前节点；满足切换条件时才寻找合格的替代节点，不会立刻随机换一个。
    删除分组
    删除该代理入口并断开已有连接，使用此地址的业务需要重新配置。不会删除订阅。

    分组操作会触发一次全组检查，其他分组也可能根据检查结果暂停或更换节点。后台恢复每轮最多尝试 3 个；手动查找或优选单次最多 100 个候选，进度显示在分组卡片。

    独立订阅来源

    同名节点按来源隔离。刷新先校验；不上传第三方转换站。

    机场标注仅用于优先筛选，不能代替真实出口验证。自动候选按美国标注优先、再按较小优先级值排序。

    只在手动操作或实际选路时检测，不定时测速。请求耗时不是 ping，旧记录会标明时间。

    告警

    仅向你配置的 HTTPS webhook 投递脱敏事件。一次有界尝试，不保证送达。

    备份与恢复

    配置备份包含订阅秘密和节点凭据，不包含质量历史和流量统计，请安全保存，不要公开分享。恢复会停止全部代理并覆盖现有配置，完成后重新验证。

    质量历史最多保留 7 天，并受容量上限约束。恢复配置保留本地历史并标记时间；重建服务器需另外保存历史。

    升级方式

    发布新版本不会自动升级。按部署文档在 1Panel 维护窗口升级；回退使用旧镜像与升级前一致备份。
