    一个分组就是一个固定的代理入口。业务使用这个入口，系统负责选择和检查背后的代理节点；换节点后，入口地址不变。

    分组怎么用？查看名词和操作说明

    首次使用：先添加并启用订阅。如果分组显示“启用分组”，先点它，再等待检查结果。需要自己选择节点时，再点“更换节点”，保留“系统自动选择”即可。只有显示“可用”后，业务才能通过该组连接。

    卡片里的代理地址供服务器上已接入共享网络的业务容器填写，不能直接填到个人电脑上。不同分组会检查出口地址是否重复；检查只覆盖设置中的检测目标，不能保证所有网站看到的地址都不同。

    节点、订阅和出口 IP
    订阅提供可选择的代理服务器，这些服务器称为“节点”；出口 IP 是检测服务器实际看到的公网地址。TCP 和 UDP 是两种通信方式，系统都会验证。
    检查连接
    立即安排一次全组检查；手动暂停的组仍保持暂停。没有合格节点时，系统可能继续寻找替代节点，这不只是测速。
    更换节点
    让系统选择或手动指定一个节点。只有通过美国归属、TCP / UDP 连接和与其他组出口不重复的检查后才可使用；切换会断开已有连接。
    启用 / 暂停分组
    启用后等待验证，不保证立即可用。暂停会停止该入口并断开已有连接，直到你再次启用。
    固定当前节点
    不允许自动更换当前节点；节点故障或验证不通过时，该组会停止转发。可以设置多久后自动解除固定，或手动解除。固定节点不等于固定公网 IP。
    允许自动换节点
    解除固定。正常时保持当前节点；满足切换条件时才寻找合格的替代节点，不会立刻随机换一个。
    删除分组
    删除该代理入口并断开已有连接，使用此地址的业务需要重新配置。不会删除订阅。

    分组操作会触发一次全组检查，其他分组也可能根据检查结果暂停或更换节点。“系统自动选择”每轮最多尝试 3 个节点，不代表一次检查完全部订阅。

    独立订阅来源

    同名节点按来源隔离。刷新先校验；不上传第三方转换站。

    机场标注仅用于优先筛选，不能代替真实出口验证。自动候选按美国标注优先、再按较小优先级值排序。
