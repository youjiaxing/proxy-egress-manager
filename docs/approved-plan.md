# 已批准的本地实施范围

用户在本会话最终 Q16 选择“1”，批准合并方案并指示开始本地实施。此前 MIT、默认公开、GHCR 和手动升级的局部确认不单独构成实施授权；本文件记录最终授权边界，不授权远程操作。

- 当前项目根直接存源码；统一业务 DNS 为 proxy-egress-manager，初始 1081/1082，可扩组；固定入口背后的节点可变。
- 多订阅独立身份、同名不串源，新增刷新不主动更换有效映射；只选择实际验证美国且组间观测 TCP/UDP 并集不交叠的出口。
- Mihomo 私有后端，自建无内核离线转发的受控网关；TCP 与 UDP 都必须真实往返和独立出口观测，不从 udp:true 或 TCP 推定 UDP 能力。
- 正常保持、不按速度切换、不自动切回；独立连通故障持续达到阈值才自动找合格备用，无独立备用暂停，不临时共享出口。
- 身份查询失败不盲切，到期暂停；独立连通计时继续。外国/冲突先阻断，无法归因则双方先停并串行重验。钉住覆盖所有故障、宁停不换，手动/定时解除，手动操作不绕规则。
- 同节点良性美国换址仍先撤销旧世代并确认旧 TCP/UDP 清理，才原子更新本组占用并释放旧差集；持久化成功后新授权恢复，不误释放他组记录。不承诺旧会话无缝。
- 调度与身份分开时效，默认 30/180/60/180 秒可配置；数据路径每次写/报文检查单调时钟与世代。重启先拒后验，不恢复旧授权；不将 Web/healthcheck/restart 冒充数据面熔断。
- 完整管理台：HTTPS+登录/会话/CSRF、订阅节点分组、检测切换暂停恢复与钉住、状态/历史/原因、可配置告警、备份恢复及脱敏诊断。无默认口令、秘密不进入普通日志、源码或镜像，不管理业务账号凭据。
- 自编代码 MIT，源码和镜像默认公开，GHCR 归用户控制账号。交付构建发布工作流、固定版本摘要及 amd64/arm64 验证流程；不得将未执行流程称为验证通过。
- 手动升级，不自动追新；预拉→停全部组件并清理→一致备份→唯一新版本先拒后验。回退统一匹配旧镜像/配置/升级前备份，明确丢失备份后配置历史。
- 本轮交付本地源码、Compose、网页、测试、构建发布流程与 1Panel/运维文档。**不含创建远程仓库、首次公开发布、VPS 上线或修改现有业务服务。** 接入条件与授权落实后才处理外部动作。
- 真实机场独立美国出口数量和可靠 UDP 观测端点未验证；无法建立则阻塞实际放行，不用 TCP 代替。固定验证目标之外目的地/地址族未知，不保证静态 IP、全站同出口、绝不风控，也不封锁业务自主直连回退。

实现取舍（Python、SQLite、固定 provider 槽位等）属于实现选择，不追溯改写为用户原始需求。当前实际验证与阻塞见 verification.md。
