# 安全、身份与保证边界

## 转发授权

每组授权绑定世代、上游入口和本地单调时钟身份期限；全局另有调度期限。有效条件是两个期限都未到、世代匹配且没有尚未完成的旧会话清理；清理期间拒绝新租约。新连接、每次用户态 TCP 写入、每个双向 UDP 数据报都检查；后台扫描只负责尽快关闭旧资源，不是安全性的唯一来源。

控制循环失效、网页仍正常时，不会无限续期；事件循环完全卡死则没有继续执行用户态转发，恢复执行先检查授权。无法撤销已交给内核/网络的数据，也不能让远端旧连接立即消失，不提供硬实时送达截止。

持久化状态不是授权。重启不会恢复租约，所有组先暂停，验证后才放行。同一数据目录以 OS 独占文件锁防止两个控制者；部署流程同时禁止新旧网关并行，文件锁不取代停止旧网关的要求。

## 出口身份与观测范围

默认 TCP：HTTPS `api.ipify.org` 返回源 IP。默认 UDP：通过 SOCKS UDP 中继向 Cloudflare / Google STUN 发送有事务标识的真实绑定请求，解析 XOR-MAPPED-ADDRESS（支持 IPv4/IPv6）。国家查询是独立的 `ipwho.is/{ip}` 元数据请求，成功才记录国家。

这些是可配置的公共服务候选，**不是已在真实机场验证可靠的承诺**。公共服务可能限流、故障或政策改变；在目标网络中验证，必要时换成自己维护的等价 HTTPS/STUN 端点。STUN 不是通用 UDP echo，不能配置不支持 STUN 的任意端口。

每个配置的 TCP 身份目标都必须成功，TCP 至少取得一个地址，并且所有已观测 TCP 地址有美国国家结果，才刷新合格身份。单一 TCP 身份目标失败不能悄悄缩小集合后释放此前占用。已知外国或冲突的 TCP 地址即使其他身份不完整也先阻断。TCP 身份查询失败本身不被解释为节点连通故障。UDP 仅作为观测指标：未响应、国家未知、非美国或与其他组地址重复，都不阻止 TCP 准入、不触发暂停或切换；保留 UDP 转发，但不保证其可用、美国归属或组间独立。

TCP 连通使用 HTTPS 控制目标；失败时以宿主直连相同目标做对照。UDP STUN 仅记录探测结果，不参与故障对照或切换计时。对照也失败则保持“未知”，不冒充独立节点故障；运行中的旧身份仍只存活到原有效期。可选 UDP 测量只使用本轮剩余预算，超时不丢弃已完成的 TCP 核验。

组间占用只包含 TCP 观测地址；UDP 地址不参与占用或冲突判断。正常不切、良性换址也先清理旧会话再原子替换本组占用，不能提前释放旧地址。碰撞无法归因时双方先停，保留占用串行重验。暂停不代表地址可给其他组；删除组也必须等撤销确认。

不保证未探测的网站、其他地址族或机场按目的地分流时同样隔离。看到 IPv4 不代表远端不会使用 IPv6，`ip-version` 不被用来虚构远端出口限制。不保证独占机场 IP、永久静态 IP、绝无风控。

## 管理面与秘密

管理员凭据部署时注入，无默认口令；PBKDF2-HMAC-SHA256（600000 次）用于内存验证，不存明文密码于数据库。会话是服务端随机标识，8 小时有效、重启失效；生产 Cookie 为 Secure / HttpOnly / SameSite=Strict。所有写操作要求准确 Origin 和会话 CSRF token，包括备份。登录失败响应节流不信任可伪造 X-Forwarded-For；正确凭据不会因反代共享地址的失败计数被固定锁住，并限制同时进行的密码校验数量。

HTTPS 由 1Panel 终止，管理服务的回环映射不对公网开放。SOCKS 是共享业务网络内的无认证服务，同网络成员视为可信；不要发布 1081/1082 或让不受信任容器加入该网络。

订阅 URL、节点秘密和告警 URL 不出现在普通状态与事件中。 编辑订阅时，已认证管理员可按需读取完整 URL，响应禁止缓存，关闭弹窗或退出登录时清除编辑表单；这不把 URL 加入普通状态或诊断。核心日志使用 silent，避免上游解析日志带出秘密；排错通过管理事件。诊断仍含出口 IP/时间，分享前检查。完整备份包含秘密，应受限保存并自行加密，不是可公开诊断文件。

仅管理员可以配置订阅与探测目标；这些配置可以访问网络资源，属于受信任配置，不向匿名请求开放。订阅只提取 proxy 定义，禁止跨节点 dialer、本地 CA 文件、接口和路由标记字段。不会执行订阅中的任意 Python/YAML 对象或导入全局路由配置。

## 明确不做

不接触业务账号密码，不修改现有业务容器，不强制阻断业务直连或其代理失败回退，不使用 Docker socket、NET_ADMIN 或透明代理，不自动升级，不自动创建远程仓库或公开发布。
