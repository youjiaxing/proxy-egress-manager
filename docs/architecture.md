# 实现与行为

## 数据与组件

一个 Python 异步进程中运行 SOCKS 网关、唯一控制者和 aiohttp 管理面。共用同一事件循环避免数据库并发写入；控制面操作另受单一 `asyncio.Lock` 串行化。数据路径不获取这把锁，避免探测或管理操作卡住时绕过授权到期。SQLite WAL + FULL synchronous 保存一个 schema=1 状态文档与有界事件表。

控制者的持久化数据：设置；订阅来源槽位/URL/启用状态；节点身份、名称、来源、优先级、禁用状态和探测结果；组固定槽位/端口、选定节点、出口集合、手动暂停、钉住和原因。运行时单调时钟 deadline、世代、任务、UDP socket 和授权不持久化。

节点 ID 是来源槽位与代理配置内容摘要，名称只作展示。同名跨来源不会混淆，配置变化产生新身份。Mihomo 文件中的代理名统一使用这个身份，不依赖不唯一的机场展示名称。

## Mihomo 对接

静态配置预声明 provider 槽位与组，业务 select 和独立 probe select 都首选 REJECT，绑定各自 TCP/UDP SOCKS listener。空订阅槽位使用一个不可达的本地 SOCKS 占位节点（不进入候选），因为 v1.19.33 不接受空 provider。

刷新时先在本地安全解析订阅、识别哪些在用节点改变/消失并撤销对应组，再原子写 provider 文件，并 `PUT /providers/proxies/sNN`。核心会独立重读该文件，不重载整份配置；失败还原旧文件。未变化的节点身份及其他组不主动切换。组映射在探测前核对，不一致先阻断再重设。

probe 入口只供控制者使用；选择候选不会改业务入口。候选初验合格后，仍须在目标业务组的核心入口复验才授予网关授权。国家/独立性失败不提交为业务映射。映射尝试过程中网关无授权，不泄漏试探流量给业务。

Mihomo v1.19.33 对接依据：`hub/route/provider.go`、`component/resource/vehicle.go`、`adapter/provider/provider.go`、`adapter/outboundgroup/selector.go`、`listener/inbound/socks.go`。固定版本，不将未核查的新版本行为当作契约。

## 控制循环

检查当前组 → 核验 TCP 身份/连通，附带有界 UDP 观测 → 汇总 TCP 碰撞归因 → 更新合格身份或先暂停 → 按独立连通故障阈值/非美国 TCP 出口/TCP 冲突/节点消失寻找备用。钉住组永不自动换节点，纯身份缺失永不盲切。身份暂停不会停止连通计时。

不确定故障不会假设恢复；没有备用继续暂停、保留不冲突占用。良性换址的提交顺序：撤销旧世代 → 等待 TCP/UDP 会话清理确认 → 验证完整 TCP 新集合/冲突 → SQLite 持久化 → 更新本地期限与授权。清理期间旧占用仍在，失败不放行。

身份期限从本次探测开始的单调时钟计算，排队等待不能给旧观测续出一个新有效期。每次有界操作前确认核心可用再更新调度期限；单次探测整体预算不超过健康宽限的 75%（并有上限）。到期扫描独立于控制锁运行，但每条转发也自行检查，所以扫描故障不能无限放行。大量分组时循环可能超过身份有效期，会安全暂停；按实际规模调整期限或扩容性能，不能用无限延期绕开保护。

## 管理 API

- `POST /api/login`、`GET /api/session`、`POST /api/logout`。
- `GET /api/state`、`GET /api/events`：秘密隐藏。
- `POST /api/action`：管理命令；返回 job ID，`GET /api/jobs/{id}` 查看结果，不让长探测占住请求。
- `POST /api/backup`：受认证/CSRF 保护的完整秘密备份；`POST /api/restore`：全局维护恢复。
- `GET /api/diagnostics`：脱敏状态；`GET /healthz`：无敏感数据的调度就绪状态。

恢复使用持久化维护标记作为跨 provider 文件与 SQLite 的崩溃屏障：失败/重启继续关闭，不能把半套恢复当正常启动。仅完整提交并清除标记后重新验证；它不是跨卷原子文件系统事务。

网页和 API 都必须遵循同一控制者路径，无旁路的“强制放行”。HTTP 正常与健康就绪是两个概念。命令记录状态改变；任务和会话有数量上限。

## 兼容与迁移

当前仅 schema=1，没有宣称跨 schema 自动迁移。新 schema 必须提供显式迁移与测试，否则拒绝恢复；版本升级回退统一使用匹配旧版本和升级前快照，不将持久化 lease 带入新进程。

TCP 是硬性准入条件；UDP 未响应、国家或 IP 变化仅更新观测，不清理业务会话、不计故障、不占用出口。UDP 测量在 TCP 核验之后使用剩余预算，包含国家查询；超时保留 TCP 结果。普通 TCP 可用不保证任意业务网站可访问，业务目标排障应单独验证。
