# 流量用量

在分组或节点的“流量用量”查看今日、本月、累计；“事件记录”页可查看全部用量，含已删除的历史分组/节点。仅打开或手动刷新时读取，明细分页返回，顶部总量涵盖所有页。北京时间自然日/月；三个时间范围相互重叠，不能相加。

上传表示客户端朝节点方向，下载为反向。按分组实际使用的节点记账，切换时冻结身份，删除并重建同名对象也不继承旧账。节点可跨组汇总；节点页单独发起的测试不归入某个业务组。不同视角是同一账，不要重复相加。

业务转发、日常验证、候选验证、手动测试分开。记录的是交给本地传输的 TCP 承载字节（包含其中 TLS）和去除 SOCKS 头的 UDP 承载字节；不是远端送达确认，不包括 IP/TCP/UDP 头、重传或节点协议封装/填充，不等于订阅商计费用量。直连国家查询、失败对照、订阅下载和 VPS 其他服务不纳入节点转发统计。不记录目的地址或订阅秘密，不能补算启用前的用量。

业务活路径只在内存累加，不逐包或逐连接写日志；每 60 秒后台保存有变化的汇总，没有变化不写盘。探测通过应用内回环计量通道到原核心入口，保持原目标和请求次数，不给业务再增加一层转发；不轮询 Mihomo 短连接，不增加外网探测。正常关闭尝试刷盘；强杀/断电可能漏掉最近一分钟及在途提交，持续写盘失败可能更长，缺口不会自动补算。

`traffic.db` 独立于配置与质量库。保留当前日、当前月及累计，不保留逐日曲线。最多 5 万汇总行或 32 MiB 记录内容，SQLite 表结构/索引/文件空间另有开销；脏内存最多 4096 个汇总键。先清过期日/月桶，不能静默删累计。达到上限或磁盘故障时明确提示记录可能不完整，已有累计保留，代理继续；原有出口身份/授权失败即停不变。成功恢复写盘也不抹去此前缺口提示。

配置备份不包含流量库，网页和离线配置恢复保留本机用量并记录恢复时间；重建服务器需另行保全统计库。停服升级时用 SQLite 一致快照单独保存，回退旧程序也保留该库，并标记旧版运行期间的未覆盖窗口。统计读取/保存/迁移失败不能自动清零或更改代理准入。

性能验收使用同机回环、交替运行旧网关与计量网关，每轮 64 MiB、首轮预热后取 7 轮中位数，并确认计数对象数不随连接/数据块增加。此类本地对照不代表生产容量、峰值或零开销保证，结果见验证记录。
